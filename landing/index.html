Motion

Gestures live on the UI thread. React only hears the result.

Animations are driven by Reanimated shared values and worklets, never by per-frame React state. A busy JS thread can't make a swipe stutter.

Tracks the finger

The bottom sheet, swipe-to-delete and swipe-back follow your touch 1:1 and settle with springs that carry your release velocity.

Interruptible

Grab the product transition mid-flight and drag it back. Nothing has to finish before you can change your mind.

Virtualised grid

1,000 products with stable keys. Rows don't re-render when the cart count changes, and tiles request images at their display size.

Instant feedback

Pressed states are drawn by the native button view, with haptics where they help, so a tap answers before any data arrives.

Respects reduce motion

With the system setting on, movement becomes cross-fades and state changes. Nothing important is lost.

Dark mode

Follows the system, with its own tuned surfaces rather than an inverted palette.

Arabic

One toggle flips everything, including which way you swipe.

Layout uses logical start and end, never left and right. Gesture and transition maths multiply by the reading direction, so swipe-to-delete and swipe-back mirror too.

Cart

Money in integer halalas. VAT shown as its own line.

Saudi shelf prices include 15% VAT, so the cart works backwards from the gross. All maths is integers, rounded once, with unit tests for quantities, totals and VAT.

vat = floor((6 × gross + 23) / 46) net = gross − vat total = gross

Built with

A production React Native stack.

Runs with no setup on a deterministic fake backend (1,000 products from a fixed seed, pages of 20, simulated latency and failures). Add Supabase keys for accounts, synced favourites and real orders, secured by Row Level Security.

Run it in three commands.

No keys needed: the fake backend starts by default. For Supabase, put the project URL and anon key in .env as EXPO_PUBLIC_SUPABASE_URL and EXPO_PUBLIC_SUPABASE_ANON_KEY.

git clone <repo> nabd && cd nabd npm install npx expo start
