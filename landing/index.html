Shelf prices include TVA, so the cart works backwards.

In Algeria, shelf prices already contain 19% TVA. The cart adds up what you pay, then takes the TVA share out of that total, rounded to the nearest centime. Every amount is a whole number of centimes, so nothing drifts by a fraction of a dinar. Change the quantities to try it.

tva = floor((38 × gross + 119) / 238)
net = gross − tva

How it's built

Expo SDK 58, Reanimated 4, Gesture Handler 3 and FlashList v2, in TypeScript.

Motion stays off the JavaScript thread
Gestures and animations run as Reanimated worklets on shared values. React state changes when a gesture ends, never on every frame, so a busy JavaScript thread can't make a swipe stutter.
A grid that holds 1,000 products
FlashList v2 recycles cells with stable keys. Tiles don't re-render when the cart count changes, and each one asks for an image at the size it is drawn, not the full 800 pixels.
Direction is a value, not a branch
Layout uses logical start and end. Gesture and transition maths multiply by the reading direction, which is why swipe to delete and swipe back mirror in Arabic without separate code paths.
A deterministic fake backend
The 1,000 products come from a fixed seed, identical on every run. The service answers in pages of 20 with a random delay and occasional failures, so the loading, empty and error states are real screens.
Reduce motion is respected
With the system setting on, movement becomes cross-fades and instant state changes. Nothing you need is lost.

Run it locally

No accounts or keys needed. The app starts on its built-in fake backend; open it in Expo Go or a development build.
