Loading: skeleton matching layout (static under reduced motion). Empty: illustration (original SVG) + one-line reason + CTA. Error: friendly localized copy + Retry; for pagination failure show inline footer retry row and keep loaded items; for product page show error state with retry and back. Never show raw error messages. Announce errors to screen readers. Make the failure visible on purpose in the demo video (judges see you handled it). Test each state in EN/AR.
